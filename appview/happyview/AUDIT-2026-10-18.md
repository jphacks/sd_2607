## Critical gaps fixed locally

`apps/web/index.html`:

- Previously only the first 50 indexed records were reachable. Added cursor-based “以前の投稿” retrieval and direct `?did=` / `?uri=` inspection. A late offline delivery remains visible in AppView arrival order, rather than being re-sorted by the author's possibly old/incorrect clock.
- Refreshes re-read the currently visible pages, deduplicate by URI and discard records removed from the refreshed snapshot. Failed partial refreshes keep the previous complete view. This is offset pagination, not an atomic server snapshot; concurrent arrivals can shift page boundaries until the next refresh.
- Added a 10-second timeout to feed and optional PLC lookups so one stalled fetch cannot lock polling forever. Display successful retrieval time and explicit stale-data/update failure status.
- Single-record API responses work with `?uri=`. BSAF originals receive a distinct label without pretending source inclusion is institutional authentication. Text remains assigned via `textContent`.

No new runtime dependencies or alternate collector. The existing native Mosimo path is functioning; replacing it with direct Nostr rendering would bypass canonical PDS publication and hide upstream failures.

For the last command replace the arguments with the originating author's DID and signed path rkey, **not** the gateway's identity, Nostr ID, or commit CID.
