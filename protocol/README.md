## 文書の読み方

- **合意済み**: 採用方針。ただし具体的な wire format が未定の項目もある。
- **構想**: 実現したい機能。標準ネットワークとの互換性を保証したものではない。
- **未決定**: 設計判断や一次仕様の検証が必要。
- **初期提案**: 比較・検討の材料。採用済みの仕様ではない。

本草案では必須・禁止・推奨を設計要件として記す。将来の規範仕様では RFC 2119 / RFC 8174 に対応する MUST・MUST NOT・SHOULD 等を定義し、適合性とテストベクトルを追加する。

文書間で相違がある場合、明示的な合意事項を優先する。`mndt.md` 内の具体的なタグ、CDDL、数値、ブロック番号を、そのまま確定した相互運用仕様として実装してはならない。

## 更新方針

未決事項は一度に一つずつ検討し、各質問への回答で合意した内容を逐次記録してコミット・pushする。公開リポジトリであるため、公開前に差分を確認し、秘密鍵・認証情報・非公開の個人情報等を含めない。未合意の選択肢を確定事項として記載しない。
