# 0004: 地理情報

状態: draft-00（方式合意、wire format と上限は未決定）

発信地点・影響範囲の型案と例は [0011](0011-extensions.md) に整理する。本書は地理情報の意味と配送上の境界を扱う。

## 1. 目的

既存アプリへの組み込み負担を抑えながら、情報の表示と配送を地理的に絞り込めるようにする。行政境界データの事前搭載やサーバーへの照会を、基本的な範囲判定の前提にしない。

## 2. 合意済みの表現

初期仕様の影響範囲は、円と Geohash によるグリッド領域を対象とする。行政区域コードと多角形は初期仕様の対象外とする。Geohash は ISO・OGC の正式な国際規格としてではなく、国に依存しない既存の公開方式として採用する。

Geohash はコードからセルの緯度・経度の範囲を復元でき、境界データの搭載を必要としない。ただし、符号化・復号・領域判定の実装コードは必要であり、アプリサイズの増加がゼロになることを保証しない。

## 3. 発信地点と影響範囲

発信地点と影響範囲は、それぞれ独立した任意の拡張単位とする。公開する値は著者署名で保護する。発信地点は影響範囲の代替ではなく、現地滞在の証明でもない。

拡張が省略された場合や受信側が解釈できない場合も、本文を受信・検証・表示できる。未知の著者署名付き拡張は改変せず保持・中継する。

Geohash の採用は影響範囲の地域コードに関する判断であり、発信地点の具体的な符号化方式を確定するものではない。

### 3.1 複数領域の意味

一つの影響範囲に複数の円・Geohash セルを指定でき、その和集合を対象領域とする。円だけ、セルだけ、または両者の混在を許容する。初期仕様では除外領域・差集合・任意の論理式を設けない。

要素数と総バイト数に上限を設ける。具体値、空の配列の扱い、正規化と符号化は未決定である。未知の要素を削って署名済みの領域を変更してはならない。

### 3.2 部分実装での包含判定

対象地点が、解釈できる要素のいずれかに含まれる場合は範囲内と判定できる。それ以外で未対応の要素等により全体を評価できない場合は、範囲外ではなく判定不明とする。全要素を評価でき、どの要素にも含まれない場合にのみ範囲外と判定できる。

これは地点の包含に関する意味規則であり、地点自身の測位誤差や数値誤差の扱いは別途定義する。範囲外・判定不明のどちらも、本文の拒否や中継の一律禁止を意味しない。

## 4. 座標系と円

発信地点と円の中心は WGS 84 の緯度・経度で表す。保存形式は固定単位の整数とし、緯度・経度は100万分の1度、円の半径・測位精度はミリメートルを1とする。表示時は度・メートルへ換算できる。atproto レコードとその CBOR は整数型を使い、自己完結した Nostr 拡張タグも内部 CBOR に同じ整数を保持する。数値をタグの値へ直接出す対応を定める場合は整数の十進文字列を用いる。初期仕様の範囲判定は地表上の二次元領域を対象とし、高度は判定に使わない。

原情報が異なる座標系や単位を使う場合は取り込み側で変換する。変換できない座標を WGS 84 として解釈してはならない。

固定単位は [0010 §3.2](0010-core.md#32-座標距離の整数表現合意済み) に従う。原値からの丸め・誤差、数値範囲、直接表現を定める場合のタグ配置、共通拡張タグの具体構文、地表距離の計算法、境界上の判定は今後定義する。Geohash への近似変換を必須とはしない。

## 5. Geohash

コードの長さによってセルの大きさが変わる。セルは緯度・経度の区間で表され、同じ文字数でも実際の幅・面積は緯度によって異なる。

隣接地点が同じ接頭辞を持つとは限らない。近隣検索を単純な接頭辞一致だけで完結できるとは扱わない。コードを領域に復号する処理と、検索・配送のための索引を区別する。

次は未決定である。


- 許容するコード長、セル数、総バイト数の上限。
- 表記の正規化、重複セルや親子セルの整理。
- セル境界、日付変更線、極付近の取り扱い。

- 原情報の領域をグリッドへ近似する場合の規則と近似であることの表示。

## 6. Nostr 上の表現

NIP-52 には位置検索用 Geohash の `g` タグという先例がある。ただし本プロトコルはカレンダーイベントの仕様を採用するものではない。本プロトコルの本文投稿は `kind: 1` であり、影響範囲と発信地点は独立した拡張として自己完結タグで運ぶ。`g` 等を直接使う方式は、標準の対象文脈・意味が一致し、全データと配列位置を失わない共通対応がある場合だけ検討する。

通常の Nostr タグ検索が接頭辞検索を保証すると仮定しない。検索のためだけの補助タグ・重複索引は追加せず、独自タグが一般リレーで検索できなくても許容する。中継者が署名済みイベントのタグを追加・変更してはならない。

## 7. 配送と安全性

影響範囲は配送順位のヒントであり、範囲外への中継の一律禁止やアクセス制限には使わない。地域外のゲートウェイへ向かう中継を許容する。地域不明を全世界対象や高優先度とは扱わない。

精度の高いセルも位置の特定につながり得る。発信地点の任意公開と精度を落とせる方針は維持する。大量のセルによる処理・通信負荷を防ぐ上限は別途定める。
