# Mosimo Webクライアント — 圏外から届いた投稿を、ブラウザーで読む

被災地の端末で作られ、オンライン側へ届いた投稿を閲覧するWebクライアントです。専用アプリを持たない離れた家族などにも、ブラウザーから情報を確認できる窓口を提供します。

**公開デモ：https://mosimo.oriom.dev**

## できること

- **タイムライン表示**：AppViewが収集したMosimo投稿とBSAF原投稿を表示します。
- **継続的な確認**：定期的な更新と、過去の投稿の追加読み込みに対応します。
- **投稿の絞り込み**：発信者や個別の投稿を指定して確認できます。

## 工夫した点

- **遅れて到着した投稿も見つけやすく**：圏外で作られた古い投稿が後から届くことを考慮し、AppViewの索引順を保って表示します。
- **出どころを混同しない**：BSAF原投稿には専用の表示を付け、Mosimoの投稿と区別します。
- **軽量な構成**：HTML・CSS・JavaScriptによる静的ページとして実装し、スマートフォンでも閲覧できます。

## 現在の対応範囲

閲覧にはインターネット接続が必要です。このWebクライアント自体は端末間の中継や投稿作成を行いません。また、投稿内容の正しさや、表示名が公的機関のものかどうかを認証する機能ではありません。

> Webクライアントを配信する構成ファイルです。 [@https://github.com/oriom-dev/podman-cluster-config](https://github.com/oriom-dev/podman-cluster-config)のためのNixOSモジュールを含みます。
