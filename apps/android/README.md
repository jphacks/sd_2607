# Mosimo Android — 圏外で投稿を作り、端末同士で運ぶ

インターネットに接続できない場所でも公開テキスト投稿を作成し、近くの端末へ渡すAndroidデモアプリです。受け取った投稿を保存し、後で別の端末へ運ぶ「バケツリレー」を担います。

## 役割・主要機能

- **圏外でも投稿**：端末内で投稿を作成し、投稿者の電子署名を付けて保存します。
- **近くの端末へ中継**：Bluetoothや同じLANで未所持の投稿を交換します。全端末が同時につながっている必要はありません。
- **オンライン復帰時に送信**：送信を有効にすると、預かった投稿を署名ごとサーバーへ届けます。
- **画面で操作・確認**：投稿、中継の開始・停止、送信先の管理、近隣端末や配送状況の確認ができます。

## 工夫した点

- **投稿者の署名を保つ**：サーバーに署名を代行させず、端末で作った署名を中継先まで引き継ぎます。
- **保存してから受け取りを知らせる**：署名の検証と暗号化保存が成功するまで受理応答を返さず、保存できなかった投稿を受理済みと見せません。
- **未配送の自作投稿を守る**：PDSサーバーが受け取るまでは、容量確保のために自作投稿を消しません。保存先が埋まった場合は、既存投稿を残して新規投稿を止めます。
- **画面を閉じても中継**：バックグラウンドでの中継と、端末再起動後の再開に対応しています。

## 実装範囲・制限

- 実験実装です。端末間通信には[暫定形式](../../protocol/mndt.md#9-android-実装の暫定値提案未採用)を使っており、最新の合意済み通信形式には未対応です。
- 公開テキストが対象です。画像・音声、投稿の削除・訂正、iOSには未対応です。署名は内容の真実性や投稿者の実社会での身元を保証しません。
- サーバーの受理応答は、Web表示までの完了を意味しません。全投稿の配送や、省電力制限・強制停止下の中継も保証しません。
- **Bluetooth中継からWeb表示までの全経路を、一続きに実証したものではありません**。確認済みの範囲と残る課題は検証記録を参照してください。
