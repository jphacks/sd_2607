# Mosimo 投稿確認ダッシュボード — 官公庁向けデモ

災害対策本部の職員が、もしもの防災やMosimo protocol対応アプリの投稿を、地図と一覧で把握・整理するためのWebアプリのデモです。閲覧専用で、投稿の作成は行いません。

## できること

- **地図・一覧・詳細を1画面に**：発信地点を点、影響範囲を円や区画として地図に表示します。訂正・補足に付いた位置も描きます。初期の表示範囲はビルド時に設定できます。
- **訂正・補足・追認のまとまり**：関連する投稿と、BSAF投稿の転載（元の投稿とURI・CIDが一致するもの）を、元の投稿の下にまとめます。元の著者が訂正した投稿は、訂正の内容を本文の上に示し、元の本文を薄く表示します。
- **状態の見分け**：情報の有効期間（有効、開始前、期限切れ）、著者が申告した優先度（重要、緊急）、訓練・試験の情報、BSAFの値（解除、注意報など）、同じ種類の拡張が複数ある投稿を、バッジで示します。期限切れの投稿は隠さず薄く表示します。
- **絞り込み**：キーワード、種類、有効状態、対応状況、地図の表示範囲、発信者で絞り込めます。表示範囲で絞り込むときは、位置が分からない投稿と、解釈できない影響範囲があって範囲内と確かめられない投稿を除外します。
- **対応状況の記録**：元の投稿ごとに未対応、対応中、対応済を記録します。関連する投稿の記録は引き継ぎません。対応済の投稿は薄く表示します。記録はそのブラウザーにだけ保存され、同じブラウザーで開いた別のタブにも反映されます。
- **新着の確認**：10秒ごとに新しい投稿を確認し、ボタンを押したときに一覧へ反映します。作業中に一覧が動くことはありません。
- **キーボードでの選別**：一覧は↑↓キーで移動しながら投稿を選べます。選んだ行からTabキーで詳細の対応状況に移り、←→キーで切り替えられます。
- **URLでの共有**：選択した投稿や発信者がURLに入るので、そのまま共有できます。

## 現在の対応範囲

AppViewから取得する投稿には身元証明チェーンが含まれていないため、すべての投稿を身元未確認として扱い、詳細で投稿ごとに「身元未確認」と表示します。著者が申告した優先度は警報と見分けられるよう、赤では表示しません。投稿内容が正しいかどうかや、発信者が公的機関であるかどうかは確かめません。ハンドルは双方向に確認できたときだけ表示し、確認できないときはDIDを表示します。

作成時刻とAppViewへの初回到着時刻（provenanceの`firstSeenAt`）がともに分かる投稿は、5分以上遅れて届いた場合に「約N分遅れで到着」と示します。作成時刻を持たない投稿は、AppViewが初めて受け取った時刻を「受信」として示します。Nostrのイベントを参照する訂正・補足は、参照先の投稿の下にまとめられません。BSAFの値は、気象庁BotとキキクルBotの値だけを日本語で示します。気象庁やCAPの拡張は、拡張の種類名を表示するだけです。発信者のDID、BSAFのタグなどは、詳細の「技術情報」に表示します。
