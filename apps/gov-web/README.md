# Mosimo 投稿確認ダッシュボード — 官公庁向けデモ

災害対策本部の職員が、もしもの防災やMosimo protocol対応アプリの投稿を、地図と一覧で把握・整理するためのWebアプリのデモです。閲覧専用で、投稿の作成は行いません。

## できること

- **地図・一覧・詳細を1画面に**：発信地点を点、影響範囲を円や区画として地図に表示します。
- **訂正・補足・追認のまとまり**：関連する投稿を元の投稿の下にまとめます。元の著者が訂正した投稿は薄く表示します。
- **状態の見分け**：情報の有効期間（有効、期限切れ、不明）、著者が付けた優先度、圏外で作られ遅れて届いた投稿を、バッジで示します。
- **絞り込み**：キーワード、種類、有効状態、地図の表示範囲、発信者で絞り込めます。
- **対応状況の記録**：投稿ごとに未対応、対応中、対応済を記録します。記録はそのブラウザーにだけ保存されます。
- **新着の確認**：10秒ごとに新しい投稿を確認し、ボタンを押したときに一覧へ反映します。作業中に一覧が動くことはありません。
- **URLでの共有**：選択した投稿や発信者がURLに入るので、そのまま共有できます。

## 現在の対応範囲

AppViewから取得する投稿には身元証明チェーンが含まれていないため、すべての投稿を「身元未確認」として表示します。投稿内容が正しいかどうかや、発信者が公的機関であるかどうかは確かめません。気象庁やCAPの拡張は、拡張の種類名を表示するだけです。
